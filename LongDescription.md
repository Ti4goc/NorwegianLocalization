# Norwegian Localization for Cities: Skylines II

A Norwegian Bokmål (`nb-NO`) translation for Cities: Skylines II, created to make the game more accessible to Norwegian-speaking players.

## Translation status

This is the first public release. The main interface, options, services, information panels, progression systems, tutorials and many generated names have already been translated.

The translation is still in active development. Some building and asset descriptions, technical asset names, downloadable content and less frequently displayed text may remain in English or require further linguistic review.

## Requirement

You must install **I18NEverywhere**, which enables this localization and allows supported mods to use Norwegian translations.

## Compatibility warning

Do not enable this mod together with another custom-language localization mod, such as a Portuguese, Dutch or other non-built-in locale. Two custom locale mods can conflict internally and cause the game to crash during startup. Enable only one custom localization mod at a time.

## Features

* Norwegian Bokmål localization for the base game
* Norwegian names for citizens, streets, districts and other generated content
* Localized interface, options, services and information panels
* Localization support for compatible mods through I18NEverywhere
* Ongoing corrections and additions
* Community translation work coordinated through [Crowdin](https://crowdin.com/project/community-localizations-csii)

## Translation and feedback

This localization is a community project and remains open to corrections, terminology improvements and native-speaker review through Crowdin.
